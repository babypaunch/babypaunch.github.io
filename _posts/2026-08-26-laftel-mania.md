영상을 볼 때 자주 쓰는 재생속도는 사람마다 다르다. 그런데 다음 영상을 열 때마다 같은 속도를 다시 고르는 일은 생각보다 자주 반복된다. Laftel Mania는 그 작은 불편을 없애려고 만든 Chrome 확장 프로그램이다.

처음 목표는 단순했다. 마지막으로 선택한 재생속도를 기억하고, 새 영상에도 그대로 적용하는 것. 지금은 `0.25x`부터 `4.00x`까지 속도를 조절하고 `Shift + ,`, `Shift + .`로 0.25배씩 바꿀 수 있다. 선택한 값은 Chrome 동기화 저장소에 보관돼 다음 영상에서도 이어진다.

## 키 입력은 보이는 글자보다 복잡했다

단축키 두 개를 붙이는 일은 간단해 보였다. 하지만 한국어 입력기가 켜지면 브라우저가 키 값을 `Process`로 전달하는 경우가 있었다. 화면에 입력된 문자만 검사하면 같은 키를 눌러도 단축키가 동작하지 않았다.

그래서 문자 값과 함께 물리 키 위치를 나타내는 `code`도 확인한다. `Comma`와 `Period`를 기준으로 판정하면 입력 언어가 바뀌어도 같은 위치의 키가 같은 기능을 수행한다. 이 동작은 Node 내장 테스트로 남겨 두었다.

## 배속 도구에서 시청 도구로

배속을 기억하는 기능을 쓰다 보니 주변 UI를 잠시 치우고 영상에만 집중하고 싶을 때가 생겼다. `Shift + M`을 누르면 페이지를 검게 가리고 영상을 화면 중앙에 표시하는 집중 모드를 추가했다.

이때 영상 요소를 다른 곳으로 옮기거나 기존 DOM을 삭제하지 않는다. 임시 CSS 클래스만 적용하기 때문에 재생 상태를 유지한 채 원래 화면으로 돌아올 수 있다. `/` 키로 여는 도움말에는 닫기 버튼, 바깥 영역 클릭, `Esc`, 키보드 초점 순환도 넣었다. 작은 도구라도 키보드만으로 사용할 수 있어야 한다고 생각했다.

## 가장 어려웠던 것은 iframe과 권한

실제 영상은 항상 `laftel.net` 문서 안에 직접 놓이지 않는다. 외부 HTTPS 플레이어 iframe 안에서 재생될 수 있다. 확장 프로그램의 실행 범위를 라프텔 도메인으로만 제한했을 때는 정작 영상 요소에 접근할 수 없어 배속 기능이 동작하지 않았다.

현재 구현은 HTTPS 프레임을 주입 대상으로 선언한 뒤, 실행 직후 현재 프레임이나 상위 프레임에 `laftel.net`이 있는지 검사한다. 라프텔과 관계없는 프레임에서는 바로 종료한다. 외부 플레이어가 바뀌어도 동작할 가능성을 높이는 대신, 설치 화면에서는 넓은 사이트 접근 권한으로 보이는 트레이드오프가 생겼다.

공개 배포 전에는 이 권한을 더 좁히는 실험이 남아 있다. 라프텔 페이지에서 실제 플레이어 주소를 확인한 뒤 그 origin만 선택적으로 승인받는 방식이 후보지만, 기존 기능이 그대로 동작하는지 먼저 증명해야 한다.

## 서버 없이, 재생속도 하나만

Laftel Mania가 저장하는 값은 마지막 재생속도 하나다. 이 값은 사용자의 Chrome 동기화 저장소에만 남고 개발자 서버로 전송되지 않는다. 로그인 정보, 방문 기록, 시청 기록이나 페이지 콘텐츠도 수집하지 않는다.

Ko-fi 후원 링크는 선택 사항이며 모든 기능은 무료다. 확장 프로그램이 결제정보를 직접 처리하지도 않는다. Laftel Mania는 라프텔이 제작하거나 승인한 공식 제품이 아닌 비공식 확장 프로그램이다. 자세한 내용은 [개인정보처리방침](https://babypaunch.github.io/public-policies/laftel-mania/privacy.html)에 정리했다.

## 지금 남은 일

현재 버전은 `1.3.0`이고 배속 기억, 물리 키 단축키, 집중 모드, 도움말과 회귀 테스트가 준비돼 있다. 다음 단계는 실제 라프텔 영상 환경에서 마지막 회귀 검사를 하고, Chrome Web Store 공개 심사를 위한 권한 구조를 결정하는 일이다.

직접 쓰려고 시작한 기능은 작았다. 하지만 입력기와 iframe, 브라우저 권한처럼 실제 환경의 모서리를 만날 때마다 제품은 조금씩 단단해졌다. BabyPaunch가 만들고 싶은 것도 이런 도구다. 거창하지 않아도 반복되는 불편 하나를 확실히 줄이는 것.
