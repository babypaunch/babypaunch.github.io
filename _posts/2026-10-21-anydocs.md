안드로이드에서 파일 하나를 열려고 했는데 생각보다 잘 안 되는 경우가 많았다.

분명 텍스트 파일인데 연결할 앱이 잘 선택되지 않거나, 확장자가 없다는 이유로 열기부터 막혔다.

메모든 로그든 설정 파일이든, 안에 들어 있는 글자만 읽으면 되는 상황이었다.

그래서 내가 편하게 쓰려고 작은 앱을 만들었다.

이름은 `anydocs`다.

<p class="article-question">텍스트로 된 파일이면 확장자와 상관없이 그냥 열어볼 수 없을까?</p>

## 확장자 없는 파일도 열어보는 앱

anydocs는 Android용 텍스트·Markdown 리더다.

파일 이름보다 실제 내용이 텍스트인지가 중요하다.

`.txt`뿐 아니라 `.log`, `.json`, `.html`, `.js`, `.yaml` 같은 파일도 원문으로 읽을 수 있다.

확장자가 없는 `README`, `LICENSE`, `Dockerfile` 같은 파일도 앱 안의 파일 열기에서 선택하면 된다.

**쉬운 설명: 파일 이름 끝에 `.txt`가 붙어 있지 않아도, 안에 글자로 된 내용이 들어 있다면 읽어보는 앱이다.**

정해진 확장자 목록에 있는 파일만 허용하는 방식은 아니다.

다만 사진이나 압축 파일처럼 실제 내용이 글자가 아닌 파일까지 문서로 보여주는 것은 아니다.

이름에 docs가 들어가지만 Word·Excel·PowerPoint·HWP·PDF를 보여주는 앱은 아니다.

처음에는 텍스트 파일을 편하게 읽는 데 범위를 두었다.

## 파일을 고르고 바로 읽기

폴더 모양의 파일 열기 버튼을 누르면 Android 파일 선택기가 나온다.

파일 관리자가 지원한다면 연결 프로그램에서 anydocs를 선택하거나 다른 앱의 공유 메뉴로 파일을 전달할 수도 있다.

연결 프로그램에 앱이 나타나지 않으면 anydocs 안에서 직접 파일을 선택하면 된다.

글자가 작으면 글자 크기를 조절하고, 긴 줄을 화면 너비에 맞춰 읽고 싶으면 자동 줄바꿈을 켠다.

코드나 로그의 줄 모양을 그대로 보고 싶으면 줄바꿈을 끄면 된다.

아이콘의 뜻이 헷갈릴 때는 길게 눌러 기능명을 확인할 수 있다.

앱 안내는 한국어 폰에서는 한국어로, 그 외 언어에서는 기본 영어로 표시한다.

열어 둔 문서의 내용이나 파일명을 번역하는 기능은 아니다.

## Markdown은 문서 형태로 보기

Markdown 파일은 원문 그대로 읽거나 제목과 목록이 구분된 문서 형태로 볼 수 있다.

**쉬운 설명: Markdown은 기호로 제목과 강조를 적는 텍스트 문서 형식이다.**

파일명 옆의 Markdown 보기 버튼을 누르면 제목·목록·인용·표·체크리스트·코드 블록을 읽기 편한 형태로 표시한다.

같은 버튼을 다시 누르면 원문 보기로 돌아오며 읽던 위치도 복원한다.

문서 변환은 인터넷으로 보내지 않고 폰 안에서 처리한다.

이미지는 실제 사진 대신 문서에 적힌 설명으로 표시하며, HTML이나 JavaScript를 실행하지 않는다.

웹 링크를 직접 누르면 외부 브라우저로 연다.

문서가 너무 크거나 복잡해 문서 보기로 바꾸기 어려운 경우에는 원문 보기로 읽을 수 있다.

## 긴 문서에서 필요한 부분 찾기

내용이 길면 처음부터 끝까지 스크롤하는 것보다 검색하는 편이 빠르다.

찾을 글자를 입력하면 문서 전체를 검색하고, 화살표로 이전·다음 결과를 이동한다.

필요하면 `Aa` 버튼으로 대소문자를 구분한다.

줄번호를 켜면 원문의 각 줄을 구분하기 쉽고, 줄 이동 버튼으로 원하는 줄번호를 직접 입력할 수도 있다.

자동 줄바꿈으로 화면에서 여러 줄처럼 보이더라도 원문의 한 줄은 같은 줄번호를 사용한다.

Markdown을 문서 형태로 보고 있다가 검색하면 원문 보기로 돌아와 해당 내용을 찾는다.

큰 텍스트는 페이지 단위로 읽어 전체 내용을 한꺼번에 화면에 올리지 않는다.

다만 큰 파일의 전체 검색에는 시간이 걸릴 수 있다.

## 글자가 깨지거나 JSON이 한 줄일 때

파일을 열었는데 한글이 이상한 기호로 보이면 인코딩을 바꿔 볼 수 있다.

**쉬운 설명: 인코딩은 저장된 데이터를 어떤 글자로 읽을지 정하는 규칙이며, 파일에 맞는 규칙을 골라야 한글이 제대로 보인다.**

자동 선택을 기본으로 사용하고, 오래된 한글 파일은 필요에 따라 `CP949`나 `EUC-KR`을 직접 선택한다.

파일 앞에 인코딩 표시가 없는 경우 자동 선택은 `UTF-8`을 기본으로 사용한다.

JSON이 한 줄로 붙어 있어 읽기 어렵다면 JSON 정렬 버튼을 누르면 된다.

**쉬운 설명: JSON은 이름과 값을 짝지어 저장하는 텍스트 형식이며, 정렬 기능은 줄바꿈과 들여쓰기를 넣어 구조를 읽기 쉽게 보여준다.**

정렬된 보기에서 다시 원문으로 돌아올 수 있다.

Markdown 보기나 JSON 정렬을 사용해도 원본 파일은 바뀌지 않는다.

## 다시 열기 편하도록

자주 읽는 파일은 제목 앞의 별표를 눌러 즐겨찾기에 넣는다.

최근 파일 목록에서는 최근에 열었던 파일과 즐겨찾기를 다시 선택할 수 있다.

파일별로 읽던 위치와 인코딩도 기억한다.

앱을 보고 있는 동안 파일 제공자가 변경을 알려주거나 크기·수정 시각이 달라지면 자동으로 다시 읽는다.

변경 정보를 제공하지 않는 앱도 있어 새로고침 버튼으로 직접 다시 읽는 방법도 남겼다.

파일을 옮기거나 접근 권한이 만료되면 최근 목록에 있더라도 파일 열기에서 다시 선택해야 한다.

## 읽기에서 편집으로, 원본은 그대로

읽는 기능을 만든 뒤에는 짧은 메모나 설정 파일의 일부를 고쳐 저장하는 기능도 추가했다.

편집본을 저장할 때는 원본을 덮어쓰는 대신 Android 파일 선택기에서 저장 위치와 이름을 정한다.

새 파일은 `UTF-8`로 저장하며 저장 후 앱에서 다시 연다.

편집 한도는 약 100만 자이고, 그보다 큰 문서는 기존 읽기 기능을 사용한다.

편집 기능은 Google Play에 공개된 `1.5.0`부터 사용할 수 있다.

Markdown 파일도 원문을 편집해 새 파일로 저장할 수 있다.

편집 메뉴가 보이지 않으면 Google Play에서 앱을 업데이트하면 된다.

## 문서를 읽는 앱이 지켜야 할 선

소스 코드까지 열 수 있게 만들고 보니 문서 안에 적힌 코드가 실행되지는 않을지도 신경 쓰였다.

`.js`나 `.html` 파일을 열어도 내용을 글자로 보여주며 열린 파일의 코드를 실행하지 않는다.

Markdown 보기에서도 JavaScript 실행과 외부 이미지·자원 불러오기를 차단한다.

**쉬운 설명: 문서에 실행 명령이 적혀 있어도 앱이 그 명령을 따라 하는 것이 아니라, 적힌 내용을 읽을 수 있게 보여준다.**

큰 문서 때문에 폰에 부담이 쌓이지 않도록 문서 변환과 JSON 정렬의 크기·복잡도를 제한하고, 임시 파일을 만들 공간이 부족하면 중단한다.

이런 제한이 있어도 읽을 수 있는 원문은 그대로 확인할 수 있도록 했다.

## 무료 앱으로 공개하며

anydocs는 회원가입이나 구독 없이 사용하는 무료 앱이며 Android 8.0 이상을 지원한다.

문서 내용은 개발자 서버로 업로드하거나 광고 요청에 전달하지 않는다.

표시에 필요한 임시 파일과 최근 파일·즐겨찾기·읽던 위치 같은 설정은 기기에 저장한다.

하단 배너 광고 한 개를 사용하며, 광고와 동의 처리에 관한 내용은 문서 처리와 구분해 개인정보처리방침에 안내한다.

[Google Play의 anydocs](https://play.google.com/store/apps/details?id=com.babypaunch.anydocs)와 [개인정보처리방침](/policies/anydocs/privacy/)에서 앱과 정보 처리 내용을 확인할 수 있다.

처음부터 많은 문서 형식을 지원하는 앱을 만들려던 것은 아니었다.

내 폰에서 텍스트 파일 하나를 쉽게 열어보고 싶어서 시작했다.

같은 이유로 파일 열기에서 막혔던 사람에게 anydocs가 작은 도움이 됐으면 좋겠다.

### <code>2026년 10월 21일</code> 추가 업데이트: Markdown 편집 기능도 공개 완료

Google Play Console에서 편집 기능이 포함된 `1.5.0`·버전 코드 `15`가 2026년 10월 13일 프로덕션에 게시됐고, 현재 출시율 `100%`로 178개 국가·지역에 제공 중인 것을 확인했다.

`.md` 문서를 열고 텍스트 편집 버튼으로 제목·목록·본문의 원문을 고친 뒤 다른 파일로 저장할 수 있다.

편집본은 `UTF-8`로 저장하며, 원본과 분리해 보관하는 방식과 약 100만 자의 편집 한도는 그대로다.

<p class="article-summary"><strong>한 줄 요약:</strong> 확장자가 없어도 텍스트 파일을 쉽게 열어볼 수 있는 간단한 Android 앱이다. Markdown 파일은 수정도 할 수 있다.</p>
