Art Of Jigsaw 싱글 개인정보처리방침

웹 싱글판과 Windows LÖVE 로컬 실행판의 로그인·이미지·저장 정보를 안내합니다. 로컬 실행도 인증·퍼즐 생성·미술품 검색에는 인터넷을 사용합니다.

최초 시행일: 2026년 10월 21일
최종 개정일: 2026년 10월 21일

적용 범위와 협동판

이 방침은 Art Of Jigsaw 싱글 웹과 Windows 원본·적응형 LÖVE 실행판에 적용됩니다. Battle Gate 협동 방과 공유 사진은 Battle Gate AOJ 협동 정책에 따릅니다. 싱글 개인 사진을 선택하는 것만으로 협동 방에 공유되지 않습니다.

로그인과 서버 요청

Google 로그인과 BabyPaunch Account(auth.babypaunch.com)가 계정을 확인합니다. Google 비밀번호는 게임이 받지 않습니다. 인증·계정 처리는 BabyPaunch Account 방침을 확인하세요. Access Gate(gate.babypaunch.com)는 인증 토큰과 칸 수·이미지 크기 등 퍼즐 생성 정보를 받아 Logic Hub의 조각 경로를 전달합니다. 싱글 개인 사진 파일 자체는 이 조각 생성 요청에 포함되지 않습니다.

내 기기에 저장하는 정보

선택한 개인 사진의 게임용 사본, 가져온 미술품·미리보기, 이미지 목록, 퍼즐 진행·점수·언어 설정과 로그인 상태를 기기에 저장합니다. PC에서는 LÖVE 사용자 저장 폴더, 웹에서는 해당 브라우저 저장소를 사용합니다. 원본 PC·적응형 비교판·웹·협동판의 저장 공간은 구분될 수 있습니다. 인증 토큰이 저장되므로 공용 기기에서는 로그아웃하고 저장 데이터를 정리하세요.

미술품·외부 서비스·접속 기록

Met 검색을 실행하면 검색어·요청 정보가 The Metropolitan Museum of Art에 전송될 수 있습니다. 이미지 요청은 Access Gate를 거칠 수 있습니다. 인증·호스팅·프록시 서비스에는 IP 주소, 요청 경로·시각·오류 등 접속 기록이 남을 수 있습니다. 게임 코드에는 광고 SDK·결제·행동 분석 SDK가 없습니다. 게임을 제공하는 BabyPaunch 사이트 공통 영역은 별도의 웹사이트 방침에 따릅니다.

보관 및 삭제

게임 내 이미지 삭제와 새 퍼즐·완료 처리에 따라 해당 이미지·진행 데이터를 정리할 수 있습니다. 모든 로컬 데이터를 삭제하려면 앱을 종료하고 해당 LÖVE 사용자 저장 폴더 또는 브라우저 사이트 저장소를 삭제하세요. 웹·PC 삭제가 다른 기기와 계정 서버 정보를 자동 삭제하지는 않습니다. BabyPaunch Account 계정 삭제는 공용 계정 방침의 요청 경로를 이용하세요.

문의와 변경

문의·삭제 요청: babypaunch@gmail.com. 비밀번호·토큰·개인 사진 원본을 보내지 마세요. 인증·전송·저장 방식이 바뀌면 방침을 갱신합니다.
