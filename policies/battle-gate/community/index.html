Community · Battle Gate

Battle Gate 이용정책·신고·차단

방 제목과 공유 사진을 포함한 사용자 콘텐츠의 허용 범위와 신고·차단 방법입니다.

최초 시행일: 2026년 10월 21일
최종 개정일: 2026년 10월 21일

1. 적용 범위와 동의

이 정책은 Battle Gate 플랫폼의 사용자 콘텐츠에 적용됩니다. 현재 제공하는 Art Of Jigsaw 협동 모드에서는 방 제목·참가자 표시 이름·공유 사진을 포함합니다. 방을 만들거나 참여하기 전에 정책 동의를 확인하고, 사진을 서버에 공유하기 전에도 동의를 확인합니다. 이후 게임을 추가하면 각 게임의 콘텐츠와 처리 범위를 별도 절에 공개합니다.

2. 공유할 수 있는 콘텐츠

본인이 만들었거나 공유할 권한이 있는 이미지·텍스트만 사용하세요. 타인의 개인정보·사진을 허가 없이 공유하지 마세요. 초대 코드를 전달하면 다른 사용자가 방에 참여할 수 있으므로 공유 사진과 방 제목을 누가 볼 수 있는지 확인하세요.

3. 금지 콘텐츠와 행동

아동 성적 학대·착취, 성적으로 노골적인 사진·음란물, 불법 콘텐츠, 위협·괴롭힘·혐오·폭력 조장, 개인정보 노출, 저작권 침해, 사칭·사기와 신고 기능 악용을 금지합니다. 비공개 초대 방에도 같은 기준이 적용됩니다. 이런 콘텐츠를 공유하도록 권장하거나 허용하지 않습니다.

4. 앱 내 신고와 차단

협동 방 헤더의 ‘신고·차단’에서 같은 방의 다른 참가자와 사유를 선택해 방 콘텐츠 또는 사용자를 신고할 수 있습니다. 설명은 선택 사항이며 500자 이내입니다. 비밀번호·인증 토큰 같은 비밀정보는 입력하지 마세요. 같은 방·사용자·사유의 중복 신고는 같은 접수로 처리하고 하루 10회까지 접수합니다. 신고 내용은 다른 참가자에게 공개하지 않습니다.

5. 차단과 해제

‘차단하고 방 나가기’를 확인하면 현재 방에서 나가며 해당 사용자와 같은 방에 새로 참여할 수 없습니다. 차단 상대도 차단한 사용자가 참여 중이거나 소유한 방에 새로 들어올 수 없습니다. 계정 화면의 ‘차단한 사용자’에서 본인이 만든 차단을 해제할 수 있습니다. 차단 목록은 최대 100명입니다. 차단은 신고 접수와 별개이며 자동으로 상대 계정 전체를 정지시키지 않습니다.

6. 운영 검토와 조치

운영자는 비공개 신고 목록을 확인하고 위반 여부에 따라 신고 종결, 해당 방 종료·공유 사진 제거 또는 대상 사용자의 게임 이용 제한을 처리할 수 있습니다. 신고만으로 자동 정지하지 않으며 자동 이미지 분류나 사전 검열을 제공한다고 주장하지 않습니다. 이용 제한 중에도 계정 화면과 계정 삭제 요청 경로는 이용할 수 있습니다. 조치에 대한 문의·이의 제기는 babypaunch@gmail.com으로 보내세요. 특정 검토 완료 시간을 보장하지 않습니다.

7. 처리 정보와 보관

정책 동의 버전·시각, 차단한 계정 식별자, 신고자·대상 계정 식별자, 게임·방 식별자, 신고 사유·설명·접수 시각·처리 상태를 보관합니다. 신고를 위해 사진 사본을 별도로 복제하거나 보관하지 않습니다. 원래 방·사진의 만료·삭제 규칙은 유지되므로 방 정리 후에는 원본 콘텐츠를 다시 열 수 없을 수 있습니다. 신고 기록은 접수 후 30일을 기준으로 주기적으로 정리합니다. 동의·차단은 계정 삭제 시 제거하고 차단은 직접 해제할 수도 있습니다. 계정 삭제 시 해당 계정이 신고자 또는 대상인 신고 기록도 제거합니다. 반복 위반 방지를 위한 계정 식별자의 해시와 이용 제한 만료 시각은 계정 삭제 후에도 제한 발급 시점부터 최대 30일간 적용하며 주기적으로 정리합니다. 일반 계정·공유 사진·백업 정보는 개인정보처리방침을 확인하세요.
