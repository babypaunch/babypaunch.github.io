Privacy · anydocs

anydocs 개인정보처리방침

문서 읽기, 기기에 저장하는 정보와 하단 배너 광고의 정보 처리를 안내합니다.

최초 시행일: 2026년 10월 9일
최종 개정일: 2026년 10월 9일

BabyPaunch가 제공하는 anydocs는 무료·읽기 전용 텍스트 및 Markdown 뷰어이며, 하단 배너 광고 한 개를 사용합니다.

문서와 파일 접근

사용자가 파일 선택기에서 고른 문서 또는 다른 앱에서 전달한 읽기 가능한 파일을 표시합니다. 문서 내용, 파일명, 파일 주소와 검색어를 개발자 서버에 업로드하거나 광고 요청에 넣지 않으며 원본 파일을 수정하지 않습니다.

HTML 및 소스 코드 파일은 문자로 표시하고 실행하지 않습니다. Markdown 보기는 문서에 포함된 HTML을 문자로 처리하며 JavaScript 실행과 외부 자원 불러오기를 차단합니다.

기기에 저장하는 정보

최근 파일 주소와 이름, 즐겨찾기, 읽던 위치, 인코딩과 표시 설정을 기기에 저장합니다. 문서 표시를 위한 임시 캐시는 앱 전용 공간에 저장하고 정상 종료 시 삭제합니다. 비정상 종료 잔여 캐시는 다음 실행에서 24시간 경과분을 정리합니다. Android 백업을 비활성화하며 별도의 캐시 암호화나 보안 삭제는 제공하지 않습니다.

광고와 개인정보 선택

Google Mobile Ads SDK와 User Messaging Platform을 사용합니다. Google SDK는 IP 주소 기반 대략적인 위치, 기기 및 광고 식별자, 광고 상호작용과 진단 정보를 광고 제공·측정·부정 이용 방지를 위해 처리할 수 있습니다. 문서 내용을 광고 SDK에 전달하지 않습니다.

필요한 지역에서는 동의 안내를 표시하고, 요구되는 경우 앱 하단의 광고 개인정보 설정에서 선택을 변경할 수 있습니다. 광고 요청은 UMP가 요청 가능하다고 판단한 뒤 수행하며, 광고 로딩이 실패해도 문서를 읽을 수 있습니다. 동의 선택과 기기 설정에 따라 광고 처리가 달라집니다.

광고 과정의 정보 처리는 Google 개인정보처리방침과 Google 광고 개인정보 안내를 따릅니다.

권한과 외부 서비스

인터넷·네트워크 상태와 Google 광고 SDK 관련 권한을 광고 및 동의 처리에 사용합니다. 문서를 읽기 위해 전체 저장소 접근 권한을 요청하지 않습니다.

문서의 웹 링크를 직접 누르면 외부 브라우저로 이동합니다. 클라우드 파일 제공자와 외부 사이트가 처리하는 정보는 각 제공자의 방침을 따릅니다.

보유 및 삭제

Android 설정에서 anydocs의 저장공간·데이터를 삭제하거나 앱을 제거하면 앱에 저장한 설정과 임시 파일이 삭제됩니다. 원본 문서는 삭제되지 않으므로 저장한 위치에서 직접 관리하세요. 회원가입이나 개발자 서버의 계정·문서 저장 기능이 없어 서버 계정 삭제 절차는 없습니다.

변경과 문의

SDK나 정보 처리 방식이 바뀌면 이 방침과 Google Play 데이터 보안 신고를 갱신합니다. 문의는 babypaunch@gmail.com으로 보내주세요. 비밀번호·키와 불필요한 개인정보는 포함하지 마세요.
