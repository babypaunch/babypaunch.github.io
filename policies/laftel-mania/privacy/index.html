Laftel Mania 개인정보처리방침

Laftel Mania가 저장하는 설정과 사이트 접근 권한을 안내합니다.

최초 시행일: 2026년 8월 25일
최종 개정일: 2026년 8월 25일

Laftel Mania는 라프텔 영상의 재생속도를 기억하고 다시 적용하기 위해 Chrome 동기화 저장소에 재생속도 값 하나를 저장합니다.

수집·저장하는 정보

  • 사용자가 마지막으로 선택한 영상 재생속도

이 정보는 사용자의 Chrome 동기화 저장소에만 저장됩니다. 개발자는 이 정보를 별도 서버로 전송하거나 수집하지 않습니다.

수집하지 않는 정보

개인 식별 정보, 로그인 정보, 결제 정보, 방문 기록, 영상 시청 기록 및 페이지 콘텐츠를 수집하거나 판매하지 않습니다.

사이트 접근 권한

라프텔 영상이 외부 HTTPS 플레이어 프레임에서 재생될 수 있어 확장 프로그램은 HTTPS 페이지에서 실행 권한을 요청합니다. 스크립트는 현재 프레임 또는 상위 프레임이 laftel.net인 경우에만 기능을 실행하고, 그 외 페이지에서는 즉시 종료합니다.

외부 후원 링크

사용자가 후원 버튼을 직접 누르면 Ko-fi의 https://ko-fi.com/babypaunch 페이지가 열립니다. 확장 프로그램은 결제정보를 직접 수집하거나 처리하지 않으며, Ko-fi와 PayPal의 개인정보처리방침이 적용됩니다. 후원은 선택 사항이고 모든 확장 기능은 무료입니다.

비공식 확장 프로그램

이 확장 프로그램은 라프텔이 제작·승인·보증하거나 라프텔과 제휴한 공식 제품이 아닙니다.
