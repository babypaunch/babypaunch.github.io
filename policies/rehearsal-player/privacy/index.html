Privacy · Rehearsal Player

Rehearsal Player 개인정보처리방침

직접 추가한 MP3, 편집 설정과 Android 광고 관련 정보가 어떻게 처리되는지 안내합니다.

최초 시행일: 2026년 10월 3일
최종 개정일: 2026년 10월 3일

BabyPaunch가 제공하는 Rehearsal Player는 이용자가 선택한 MP3의 구간을 듣고 반복 연습하는 앱입니다. 회원가입이나 로그인을 요구하지 않습니다. 음악 파일과 편집 설정을 개발자 서버로 업로드하지 않습니다.

기기에 저장되는 음악과 설정

이용자가 추가한 MP3, 파형 요약, 구간·페이드 설정은 기기의 앱 저장 공간에 보관합니다. Android에서는 화면이 꺼져도 재생할 수 있도록 선택한 MP3의 사본을 앱 내부 저장소에 만듭니다. 앱은 이용자가 선택하지 않은 음악 파일을 임의로 읽지 않습니다.

파일 내보내기와 공유

편집본 MP3를 저장하거나 공유하면 Android 공유 화면에서 이용자가 선택한 앱 또는 저장 위치로 파일을 전달합니다. 그 이후의 처리는 선택한 앱이나 서비스의 방침을 따릅니다. 웹 버전에서는 이용자가 선택한 다운로드 위치에 편집본을 저장합니다.

광고와 개인정보 선택

Android 앱은 Google AdMob의 하단 배너 광고를 사용합니다. Google Mobile Ads SDK는 광고 제공, 측정과 부정 사용 방지를 위해 IP 주소, IP 주소에서 추정한 대략적인 위치, 앱 상호작용, 진단 정보, 광고 식별자 등 기기 식별자를 수집하여 Google과 공유할 수 있습니다. 자세한 내용은 Google Mobile Ads SDK 데이터 공개 안내와 Google 개인정보처리방침을 확인하세요.

필요한 지역에서는 Google User Messaging Platform의 동의 화면을 표시합니다. 앱은 동의 상태에서 광고 요청이 허용될 때에만 배너를 요청합니다. 개인정보 옵션이 필요한 경우 앱의 곡 목록 머리글에 표시되는 방패 버튼에서 선택을 다시 확인하거나 변경할 수 있습니다. 웹 버전에는 이 Android 광고 SDK가 없습니다.

직접 수집하지 않는 정보와 권한

개발자는 이름, 이메일 주소, 전화번호, 연락처, 사진, 마이크 녹음, 음악 파일이나 편집 설정을 직접 수집하거나 판매하지 않습니다. 계정, 개발자용 원격 분석 또는 음악 업로드 서버를 운영하지 않습니다. 광고 과정에서 Google이 처리하는 정보에는 위 Google 방침이 적용됩니다.

Android 앱은 광고 및 동의 확인에 인터넷 권한을, 화면 잠금 중 오디오 재생에 미디어 재생 서비스와 wake lock을 사용합니다. 연락처, 카메라, 마이크, 정확한 위치 또는 전체 파일 저장소에 접근하는 권한은 요청하지 않습니다. 앱은 평문 네트워크 통신을 허용하지 않습니다.

보유 및 삭제

앱의 곡 목록에서 곡을 제거하면 해당 곡의 앱 내부 파일과 편집 설정을 삭제합니다. Android 설정에서 앱 데이터를 지우거나 앱을 제거하면 나머지 로컬 데이터도 삭제됩니다. 이용자의 원본 MP3와 별도로 내보낸 편집본은 원래 저장한 위치에 남으므로 해당 위치에서 직접 삭제해야 합니다. 개발자 서버에는 삭제할 계정이나 업로드된 음악이 없습니다. Google이 광고 과정에서 처리한 정보의 보유와 삭제는 Google 방침 및 기기의 광고 개인정보 설정을 따릅니다.

아동의 개인정보

Rehearsal Player는 아동을 주요 대상으로 설계하지 않았습니다. 보호자는 기기의 앱 데이터와 광고 개인정보 설정을 관리할 수 있습니다.

방침 변경

앱 기능, 광고 SDK 또는 데이터 처리가 변경되면 실제 동작에 맞게 이 방침과 Google Play 데이터 보안 정보를 갱신합니다. 이 정책 페이지를 방문할 때 BabyPaunch 웹사이트가 처리하는 정보는 BabyPaunch 웹사이트 개인정보처리방침을 확인하세요.
