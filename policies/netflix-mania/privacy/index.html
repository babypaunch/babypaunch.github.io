Privacy · Netflix Mania

Netflix Mania 개인정보처리방침

Netflix Mania의 데이터 처리와 Netflix 사이트 접근 범위를 안내합니다.

최초 시행일: 2026년 9월 2일
최종 개정일: 2026년 9월 2일

Netflix Mania는 Netflix 웹 플레이어의 기본 재생속도 메뉴를 키보드로 조절하기 위한 Chrome 확장 프로그램입니다.

수집·저장하는 정보

Netflix Mania는 개인정보, 설정값 또는 이용 기록을 수집하거나 저장하지 않습니다.

수집하지 않는 정보

개인 식별 정보, Netflix 로그인 정보, 결제 정보, 방문 기록, 영상 시청 기록 및 페이지 콘텐츠를 수집하거나 판매하거나 외부로 전송하지 않습니다.

사이트 접근 권한

확장 프로그램은 단축키 입력을 감지하고 Netflix의 기본 배속 메뉴를 선택하기 위해 https://www.netflix.com/*에서만 실행됩니다. 다른 사이트에서는 실행되지 않으며 개발자 서버와 통신하지 않습니다.

외부 후원 링크

사용자가 후원 버튼을 직접 누르면 Ko-fi의 https://ko-fi.com/babypaunch 페이지가 열립니다. 확장 프로그램은 결제정보를 직접 수집하거나 처리하지 않으며 Ko-fi와 결제 서비스의 개인정보처리방침이 적용됩니다. 후원은 선택 사항이고 모든 확장 기능은 무료입니다.

비공식 확장 프로그램

이 확장 프로그램은 Netflix가 제작·승인·보증하거나 Netflix와 제휴한 공식 제품이 아닙니다.

개정 이력

정해진 일정에 맞춰 날짜만 갱신하지 않으며, 방침 내용이 변경된 경우 최종 개정일과 아래 이력에 기록합니다.
