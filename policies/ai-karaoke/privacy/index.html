AI-Karaoke 개인정보처리방침

현재 탭의 오디오 처리, 개인 노래방 책과 데이터 삭제 방법을 안내합니다.

최초 시행일: 2026년 10월 21일
최종 개정일: 2026년 10월 21일

운영자: BabyPaunch · 문의: babypaunch@gmail.com

AI-Karaoke는 Transpose, Vocal Remove와 사용자가 직접 준비한 가사·싱크를 제공하는 Chrome 확장 프로그램입니다. 현재 기능은 로그인·일일 곡 수 제한·결제 없이 무료로 제공합니다.

처리하는 정보와 목적

탭 오디오

목적: 사용자가 요청한 조옮김과 보컬 감소

처리: 브라우저 메모리에서 일시 처리하며 오디오 파일로 저장하거나 개발자 서버로 전송하지 않습니다. AI 모델과 WASM은 확장에 포함되며 WebGPU와 하드웨어 가속이 필요합니다.

가사와 싱크

목적: 직접 선택한 TXT/LRC·곡 JSON의 가사 표시와 Index 시작 시간 재사용

저장: 확장 전용 IndexedDB에 사용자가 삭제할 때까지 보관합니다.

영상 정보

목적: YouTube·YouTube Music의 URL·영상 ID·제목·채널명으로 곡 식별, 검색과 영상 연결

저장: 확장 전용 IndexedDB에 사용자가 삭제할 때까지 보관하며 개발자 서버로 전송하지 않습니다.

설정과 사용 시각

목적: 한국어·English 선택과 최근 곡 정렬

저장: UI 언어는 chrome.storage.local, 최근 곡 사용 시각은 IndexedDB에 저장합니다. 설정 갱신·곡 삭제 또는 확장 제거 시까지 보관합니다.

처리 시작과 Chrome 권한

탭 오디오는 사용자가 팝업에서 Transpose 또는 Vocal Remove를 선택할 때 처리합니다. 가사 파일은 사용자가 파일을 선택할 때 읽습니다. 노래방 UI는 https://www.youtube.com/*와 https://music.youtube.com/*에서 실행됩니다.

  • activeTab: 사용자가 조작한 현재 탭 식별
  • tabCapture: 사용자가 요청한 탭 오디오 처리
  • offscreen: 팝업이 닫힌 후에도 시작한 오디오 처리 유지
  • scripting: 지원 화면에 확장에 포함된 가사 UI와 스타일 연결
  • storage: UI 설정과 이전 버전 저장 자료 관리

외부 전송과 선택적 링크

현재 확장은 개발자 계정·사용량·결제 서버, 외부 광고 SDK와 분석 서비스를 연결하지 않습니다. 로그인 정보·결제정보를 조회하지 않으며, 오디오·가사·싱크·영상 정보를 개발자 API나 광고 사업자에게 전송하거나 판매하지 않습니다.

Support의 Humming Echo-Sweet Like Cookies는 사용자가 선택할 때만 YouTube 새 탭에서 열립니다. 자동 재생·사전 로드·클릭 추적을 추가하지 않으며 noreferrer를 적용합니다. 이동 후의 데이터 처리는 YouTube의 방침을 따릅니다. Support 이용은 무료 기능의 조건이 아닙니다.

웹스토어 공유 버튼은 공식 주소가 설정된 경우에만 그 링크를 클립보드에 씁니다. 클립보드의 기존 내용을 읽거나 다른 데이터를 함께 공유하지 않습니다. 이 정책 웹페이지의 분석·쿠키 처리는 BabyPaunch 웹사이트 개인정보처리방침을 따릅니다.

보유 및 데이터 삭제

현재 영상의 가사 제거로 해당 곡의 가사와 Index 시간을 삭제할 수 있습니다. 전체 복원은 확인 후 현재 노래방 책을 백업 내용으로 교체합니다. 필요하면 먼저 전체 백업을 보관하세요.

확장을 제거하면 Chrome이 확장 전용 로컬 설정과 IndexedDB를 제거합니다. 내보낸 JSON·백업 파일과 내려받은 TXT 예제는 확장 밖의 파일이므로 사용자가 직접 삭제해야 합니다. 현재 서버 계정은 없으며 운영자가 사용자의 로컬 저장소를 대신 열거나 삭제할 수 없습니다.

이전 시험 버전의 로컬 사용량이 남아 있어도 현재 무료 기능을 제한하거나 외부로 전송하는 데 사용하지 않습니다. 해당 자료는 확장 제거 시 함께 삭제됩니다.

가사와 콘텐츠 권리

노래 가사는 사용자가 직접 준비합니다. 도움말의 TXT 예제는 작성 형식을 보여주는 문구이며 실제 노래 가사를 제공하지 않습니다. 사용자는 영상·가사·곡 JSON 이용과 공유에 필요한 권리를 확인해야 합니다. 확장은 YouTube·Google·Chrome의 공식 또는 제휴 제품이 아닙니다.

Chrome Web Store Limited Use

Google API에서 받은 정보는 공개한 노래 연습 기능에만 사용하며 광고, 데이터 판매나 공개하지 않은 목적으로 사용하지 않습니다.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
