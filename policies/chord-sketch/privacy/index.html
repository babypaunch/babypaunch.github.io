Chord Sketch 개인정보처리방침

Chord Sketch가 앱 설정과 스케치 파일을 어떻게 처리하는지 안내합니다.

최초 시행일: 2026년 9월 1일
최종 개정일: 2026년 9월 1일

BabyPaunch가 제공하는 Chord Sketch는 회원가입이나 로그인을 요구하지 않으며, 개발자가 운영하는 서버로 개인정보나 사용자가 만든 코드 스케치를 전송하지 않습니다.

앱이 처리하는 정보

언어, 시작 안내 확인 여부, 프리셋 즐겨찾기와 최근 사용 기록은 앱을 편리하게 사용할 수 있도록 기기 안에 저장됩니다. 사용자가 만든 코드 진행은 앱에서 편집되며, 사용자가 직접 내보내기를 선택할 때만 JSON 파일로 만들어집니다.

파일 가져오기와 내보내기

가져올 JSON 파일은 사용자가 Android 파일 선택기에서 직접 고릅니다. 내보낸 파일은 Android 공유 화면에서 사용자가 선택한 앱 또는 위치로 전달됩니다. Chord Sketch는 사용자가 선택하지 않은 다른 파일을 읽거나 업로드하지 않습니다. 공유 이후의 처리는 사용자가 선택한 서비스의 방침을 따릅니다.

수집하지 않는 정보

현재 버전은 이름, 이메일 주소, 전화번호, 위치, 연락처, 사진, 마이크 녹음, 결제정보, 광고 식별자 또는 사용 분석 정보를 수집하거나 판매하지 않습니다. 광고, 사용자 계정, 원격 분석과 개발자 운영 서버를 사용하지 않습니다.

권한과 네트워크

앱은 Android의 인터넷 권한을 포함하지만 현재 핵심 기능은 앱에 포함된 자원으로 실행됩니다. 기기의 다른 개인 파일, 연락처, 위치 또는 마이크에 접근하는 권한은 요청하지 않습니다.

보유 및 삭제

앱 설정은 기기에만 남으며 Android 설정에서 Chord Sketch의 저장공간 또는 데이터를 삭제하거나 앱을 제거하면 삭제됩니다. 사용자가 별도로 내보낸 JSON 파일은 저장한 앱이나 위치에서 직접 삭제해야 합니다. 개발자 서버에 계정이나 스케치가 없으므로 개발자가 대신 삭제할 서버 데이터는 없습니다.

자세한 절차는 Chord Sketch 데이터 삭제 안내에서 확인할 수 있습니다.

아동의 개인정보

Chord Sketch는 아동을 주요 대상으로 설계한 앱이 아닙니다. 개인정보를 직접 수집하는 기능은 없지만, 보호자는 자녀의 기기와 내보낸 파일을 기기 설정에서 관리할 수 있습니다.

방침 변경

광고, 결제, 분석 또는 서버 기능을 추가하는 경우 해당 기능을 공개하기 전에 실제 처리 내용에 맞게 이 방침과 Google Play 데이터 보안 정보를 갱신합니다.
