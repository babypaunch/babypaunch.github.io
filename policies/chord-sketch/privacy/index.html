Privacy · Chord Sketch

Chord Sketch 개인정보처리방침

Chord Sketch가 앱 설정과 스케치 파일을 어떻게 처리하는지 안내합니다.

최초 시행일: 2026년 9월 1일
최종 개정일: 2026년 9월 1일

BabyPaunch가 제공하는 Chord Sketch는 회원가입이나 로그인을 요구하지 않으며, 개발자가 운영하는 서버로 개인정보나 사용자가 만든 코드 스케치를 전송하지 않습니다. 무료 버전은 Google AdMob 배너 광고를 표시하고, Google Play를 통해 자동 갱신 없는 Pro 1개월 선불 구독을 제공합니다.

앱이 처리하는 정보

언어, 시작 안내 확인 여부, 프리셋 즐겨찾기와 최근 사용 기록은 앱을 편리하게 사용할 수 있도록 기기 안에 저장됩니다. 사용자가 만든 코드 진행은 앱에서 편집되며, 사용자가 직접 내보내기를 선택할 때만 JSON 파일로 만들어집니다.

파일 가져오기와 내보내기

가져올 JSON 파일은 사용자가 Android 파일 선택기에서 직접 고릅니다. 내보낸 파일은 Android 공유 화면에서 사용자가 선택한 앱 또는 위치로 전달됩니다. Chord Sketch는 사용자가 선택하지 않은 다른 파일을 읽거나 업로드하지 않습니다. 공유 이후의 처리는 사용자가 선택한 서비스의 방침을 따릅니다.

광고와 개인정보 선택

Google Mobile Ads SDK는 광고 제공, 부정 사용 방지, 측정과 진단을 위해 광고 식별자, 기기 또는 기타 식별자, 대략적인 위치, 앱 상호작용과 진단 정보를 처리할 수 있습니다. 필요한 지역에서는 Google User Messaging Platform의 동의 화면을 먼저 표시하며, 앱의 개인정보 옵션에서 선택을 다시 확인하거나 변경할 수 있습니다. 자세한 내용은 Google 개인정보처리방침을 따릅니다.

Pro 1개월 선불 구독

결제는 Google Play Billing이 처리합니다. Pro 이용권은 구매일부터 1개월 동안 광고를 제거하고 전체 Pro 프리셋을 제공하며 자동 갱신되지 않습니다. 앱은 활성 이용권 확인과 복원을 위해 Google Play의 구매 상태를 확인하지만, 개발자는 카드번호나 은행 계좌 정보를 직접 수집하거나 보관하지 않습니다.

직접 수집하지 않는 정보

개발자는 이름, 이메일 주소, 전화번호, 연락처, 사진, 마이크 녹음 또는 사용자가 만든 코드 스케치를 직접 수집하거나 판매하지 않습니다. 사용자 계정, 원격 분석과 개발자 운영 서버를 사용하지 않습니다. 광고와 결제 과정에서 Google이 처리하는 정보에는 Google의 방침이 적용됩니다.

권한과 네트워크

앱은 광고, 동의 확인과 구매 상태 확인을 위해 Android 인터넷 권한을 사용합니다. 핵심 코드 스케치 기능은 앱에 포함된 자원으로 실행되며, 기기의 다른 개인 파일, 연락처, 위치 또는 마이크에 접근하는 권한은 요청하지 않습니다.

보유 및 삭제

앱 설정은 기기에만 남으며 Android 설정에서 Chord Sketch의 저장공간 또는 데이터를 삭제하거나 앱을 제거하면 삭제됩니다. 사용자가 별도로 내보낸 JSON 파일은 저장한 앱이나 위치에서 직접 삭제해야 합니다. 개발자 서버에 계정이나 스케치가 없으므로 개발자가 대신 삭제할 서버 데이터는 없습니다.

자세한 절차는 Chord Sketch 데이터 삭제 안내에서 확인할 수 있습니다.

아동의 개인정보

Chord Sketch는 아동을 주요 대상으로 설계한 앱이 아닙니다. 개인정보를 직접 수집하는 기능은 없지만, 보호자는 자녀의 기기와 내보낸 파일을 기기 설정에서 관리할 수 있습니다.

방침 변경

앱 기능, 광고·결제 SDK 또는 관련 법령이 변경되면 실제 처리 내용에 맞게 이 방침과 Google Play 데이터 보안 정보를 갱신합니다.
