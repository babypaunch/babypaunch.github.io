Privacy · BabyPaunch

개인정보처리방침

BabyPaunch 웹사이트에서 처리되는 정보와 외부 서비스 사용 방식을 안내합니다.

최초 시행일: 2026년 8월 26일
최종 개정일: 2026년 8월 28일

수집하는 개인정보

BabyPaunch는 이 웹사이트에서 회원가입, 로그인, 댓글 또는 문의 양식을 운영하지 않으며 방문자의 개인정보를 직접 수집하거나 별도로 저장하지 않습니다.

웹사이트 호스팅

이 웹사이트는 GitHub Pages를 통해 제공됩니다. GitHub는 서비스 운영과 보안을 위해 접속 기록이나 기기 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침에서 확인할 수 있습니다.

외부 콘텐츠와 링크

음악과 블로그 페이지에는 YouTube 및 Spotify 콘텐츠가 포함될 수 있습니다. 방문자가 해당 콘텐츠를 재생하거나 이용하면 각 서비스가 쿠키, IP 주소, 기기 정보와 이용 기록을 Google 개인정보처리방침과 Spotify 개인정보처리방침에 따라 처리할 수 있습니다.

외부 사이트로 이동한 뒤의 정보 처리는 해당 사이트의 개인정보처리방침이 적용됩니다.

방문 분석과 동의

BabyPaunch는 사용자가 분석을 허용한 경우에만 Google Analytics를 불러옵니다. Google Analytics는 방문한 페이지, 유입 경로, 대략적인 기기·브라우저 정보와 사이트 이용 이벤트를 처리하여 어떤 글과 유입 채널이 도움이 되는지 집계합니다. BabyPaunch는 이 정보로 방문자의 실명을 확인하거나 회원 프로필을 만들지 않습니다.

분석을 거부하면 Google Analytics 스크립트를 불러오지 않으며 사이트 기능에는 영향이 없습니다. 선택은 브라우저의 로컬 저장소에 보관되고, 페이지 아래의 에서 언제든지 변경할 수 있습니다. Google의 정보 처리 방식은 Google 개인정보처리방침에서 확인할 수 있습니다.

광고

BabyPaunch는 현재 Google AdSense 광고 코드를 사용하지 않습니다. 향후 광고를 도입하면 광고 쿠키, 맞춤 광고 여부와 필요한 동의 항목을 이 방침과 동의 화면에 먼저 반영합니다.

방침의 변경

서비스 구성이나 관련 법령이 변경되면 이 방침을 수정할 수 있습니다. 정해진 일정에 맞춰 날짜만 갱신하지 않으며, 실제 내용이 변경된 경우 최종 개정일과 아래 이력에 기록합니다.
