Privacy · Echo Note

Echo Note 개인정보처리방침

Echo Note가 학습 설정, 기기 음성과 광고 관련 정보를 어떻게 처리하는지 안내합니다.

최초 시행일: 2026년 9월 13일
최종 개정일: 2026년 9월 13일

BabyPaunch가 제공하는 Echo Note는 Android WebView에서 실행되는 하이브리드 영단어 학습 앱입니다. 회원가입이나 로그인을 요구하지 않으며, 개발자가 운영하는 서버로 학습 내용이나 개인정보를 전송하지 않습니다. 앱은 Google AdMob 하단 배너 광고로 운영됩니다.

기기에 저장되는 학습 설정

화면 언어, 번역 언어, 북마크, 숨긴 단어, 카드별 반복 횟수와 음성 재생 속도는 앱을 계속 사용할 수 있도록 Android WebView의 로컬 저장소에 보관됩니다. 단어와 번역 데이터는 앱에 포함되어 있으며 개발자 서버에서 내려받지 않습니다. 셀프 테스트에 입력한 답은 현재 화면에서 채점한 뒤 개발자에게 전송하거나 별도로 저장하지 않습니다.

기기 음성

Android 앱은 기기에 설치된 오프라인 영어 Text-to-Speech 음성을 사용해 단어를 읽습니다. Echo Note는 마이크 권한을 요청하거나 사용자의 음성을 녹음하지 않습니다. 사용할 수 있는 음성과 음성 엔진의 동작은 기기 및 해당 음성 엔진 제공자의 설정을 따릅니다.

광고와 개인정보 선택

Echo Note는 Google Mobile Ads SDK를 통해 하단 배너 광고를 표시합니다. 이 SDK는 광고 제공, 분석과 부정 사용 방지를 위해 IP 주소를 통한 대략적인 위치, 앱 실행·탭 등 앱 상호작용, 앱과 SDK의 진단 정보, 광고 식별자와 앱 세트 ID를 포함한 기기 또는 기타 식별자를 자동으로 수집하고 Google과 공유할 수 있습니다. 자세한 기술 정보는 Google Mobile Ads SDK 데이터 공개 안내와 Google 개인정보처리방침에서 확인할 수 있습니다.

필요한 지역에서는 Google User Messaging Platform의 동의 화면을 표시한 뒤 허용된 상태에 따라 광고를 요청합니다. 개인정보 옵션이 필요한 경우 앱 전역 헤더의 개인정보 선택 버튼에서 선택을 다시 확인하거나 변경할 수 있습니다.

직접 수집하지 않는 정보

개발자는 이름, 이메일 주소, 전화번호, 연락처, 사진, 위치 정보, 마이크 녹음, 북마크, 숨긴 단어 또는 셀프 테스트 답안을 직접 수집하거나 판매하지 않습니다. 사용자 계정, 개발자용 원격 분석과 개발자 운영 서버를 사용하지 않습니다. 광고 과정에서 Google이 처리하는 정보에는 Google의 방침이 적용됩니다.

권한과 네트워크

앱은 광고 요청과 개인정보 선택 확인을 위해 Android 인터넷 권한을 사용합니다. 학습 화면과 단어·번역 데이터는 앱 패키지에 포함됩니다. 연락처, 사진, 개인 파일, 정확한 위치 또는 마이크에 접근하는 권한은 요청하지 않습니다.

보유 및 삭제

학습 설정은 기기에만 남습니다. Android 설정에서 Echo Note의 저장공간 또는 데이터를 삭제하거나 앱을 제거하면 로컬 저장 정보가 삭제됩니다. 개발자 서버에 계정이나 학습 기록이 없으므로 개발자가 대신 삭제할 서버 데이터는 없습니다. Google이 광고 과정에서 처리하는 정보의 보유와 삭제는 Google의 방침과 Android 광고 ID 설정을 따릅니다.

아동의 개인정보

Echo Note는 아동을 주요 대상으로 설계한 앱이 아닙니다. 앱이 개인정보를 직접 수집하는 기능은 없지만, 보호자는 자녀의 기기 설정과 광고 개인정보 선택을 관리할 수 있습니다.

방침 변경

앱 기능, 하이브리드 구성, 음성 엔진, 광고 SDK 또는 관련 법령이 변경되면 실제 처리 내용에 맞게 이 방침과 Google Play 데이터 보안 정보를 갱신합니다.
