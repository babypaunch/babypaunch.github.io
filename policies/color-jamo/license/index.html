접근과 변경 권한

이 정책 페이지와 웹폰트는 읽기 전용 정적 파일로 제공됩니다. Color Jamo 공개 경로에는 폰트 업로드·편집·계정 생성 기능이나 업로드 API가 없습니다. 방문자가 브라우저에서 파일을 읽는 것만으로 사이트 저장소를 변경할 수 없습니다. 공개 파일 변경은 BabyPaunch 저장소의 쓰기 권한이 있는 사용자만 할 수 있습니다.

표시 범위와 사이트 정보

이 글꼴은 한글 완성형 11,172자와 기본 ASCII 95자를 포함합니다. 한글 자모 계열 획에는 파랑 #287FE0과 주황 #F07836의 COLR v0 색상 레이어를 사용합니다. 브라우저나 운영체제의 컬러 글꼴 지원에 따라 표시가 달라질 수 있습니다. 모든 글자의 자모 획 구분을 시각적으로 검수했다는 뜻은 아닙니다.

아래 예시는 BabyPaunch 또는 별도 사용 허락을 받은 사이트를 위한 것입니다. 폰트 표시에는 CSS만 필요합니다.

작은 본문에서는 고대비 또는 검정색 클래스를 사용하세요. 팔레트를 지원하지 않는 브라우저는 원래 색상으로 표시될 수 있습니다.

로마자 발음 변환에는 아래 스크립트를 순서대로 불러옵니다. 변환은 브라우저 안에서 수행되며 API 자체는 텍스트를 전송하거나 저장하지 않습니다.

<script src="https://babypaunch.com/assets/fonts/color-jamo/v1.0/koroman.browser.js"></script>
<script src="https://babypaunch.com/assets/fonts/color-jamo/v1.0/color-jamo.js"></script>
<script>
  ColorJamo.romanize("국물", { syllableSeparator: "_" }); // gung_mul
  ColorJamo.withPronunciation("국물"); // 국물\ngungmul
</script>

syllableSeparator는 빈 문자열·공백·밑줄을 지원합니다. 문장부호와 영문을 유지하고, withPronunciation은 한글이 있는 줄 아래에 발음을 붙입니다. 일부 단어·고유명사의 발음은 다를 수 있습니다. 반환값은 textContent로 표시하세요.

Koroman MIT 고지는 재제공 시 유지해야 합니다. 폰트 이용 조건과 제삼자 라이브러리의 MIT 조건은 별개입니다. 공개 파일 SHA-256 목록을 제공합니다.
