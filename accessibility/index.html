Accessibility · BabyPaunch

접근성 안내

BabyPaunch는 더 많은 사람이 콘텐츠를 읽고 탐색할 수 있는 웹사이트를 지향합니다.

최종 갱신일: 2026년 8월 26일

접근성 목표

이 웹사이트는 웹 콘텐츠 접근성 지침 WCAG 2.2의 AA 수준을 목표로 설계하고 개선합니다. 새 페이지와 기능도 같은 기준을 따릅니다.

지원하는 기능

  • 본문으로 바로 이동하는 건너뛰기 링크
  • 키보드만으로 이용할 수 있는 탐색과 태그 필터
  • 현재 위치와 포커스를 구분하는 시각적 표시
  • 스크린리더가 이해할 수 있는 제목, 영역, 링크와 이미지 설명
  • 한국어와 영어 페이지 및 문장별 언어 정보
  • 브라우저의 모션 감소와 고대비 설정 지원
  • 화면 확대와 모바일·태블릿·PC 레이아웃 지원

알려진 제한 사항

YouTube와 Spotify 플레이어는 외부 서비스가 제공하는 콘텐츠입니다. 플레이어 내부의 접근성과 키보드 동작은 각 서비스의 구현에 따라 달라질 수 있습니다.
