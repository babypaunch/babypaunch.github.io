Support · Chord Sketch

코드 스케치 - 작곡 공부 지원

코드를 직접 듣고 조합하며 배우는 Chord Sketch의 사용법과 파일 보관 방법을 안내합니다.

Google Play에서 코드 스케치 보기

앱 사용

코드 휠에서 조와 Major·Minor를 선택하고 코드를 눌러 소리를 들을 수 있습니다. 4코드 스케치의 슬롯을 먼저 선택하면 누른 코드가 해당 슬롯에 입력됩니다. BPM과 박자를 조절하고 전체 또는 블록 단위로 반복 재생할 수 있습니다.

180개 프리셋에서 마음에 드는 진행을 고른 뒤 코드 하나를 바꿔 들어보세요. 피아노 구성음, 장조·단조, 템포와 박자를 비교하며 작곡을 연습할 수 있습니다. 모든 기능과 프리셋은 무료이며 하단 배너 광고가 표시됩니다.

스케치 파일

내보내기는 현재 스케치를 JSON 파일로 만들어 Android 공유 화면을 엽니다. 가져오기는 Chord Sketch가 내보낸 JSON 파일을 Android 파일 선택기에서 직접 선택하는 방식입니다. 스케치는 자동 저장되지 않으므로 앱을 닫기 전에 별도 위치에 내보내 보관하세요.

데이터 삭제

Chord Sketch에는 계정이나 개발자 서버에 저장되는 사용자 데이터가 없습니다. 기기에 저장된 앱 설정은 아래 방법으로 삭제할 수 있습니다.

앱 설정 삭제

경로: Android 설정 → 애플리케이션 → Chord Sketch → 저장공간 → 데이터 삭제

앱과 설정 삭제

방법: Chord Sketch를 제거하면 앱 내부 설정도 함께 삭제됩니다.

내보낸 파일 삭제

방법: 파일을 저장하거나 공유한 앱에서 해당 JSON 파일을 직접 삭제합니다.

서버에 계정이나 스케치가 저장되지 않으므로 별도의 계정 삭제 신청은 필요하지 않습니다.

문제 신고와 문의
