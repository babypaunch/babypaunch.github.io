Display scope and site information

The font includes 11,172 precomposed Hangul syllables and the 95 basic ASCII characters. Its Hangul jamo-related strokes use blue #287FE0 and orange #F07836 COLR v0 color layers. Display can vary with browser and operating-system color-font support. This does not mean that every glyph's jamo-stroke division has been visually verified.

Using the webfont and JavaScript

These examples are for BabyPaunch or sites with separate permission. Font display only requires CSS.

<link rel="stylesheet" href="https://babypaunch.com/assets/fonts/color-jamo/v1.0/color-jamo.css">
<p class="color-jamo color-jamo-contrast">가나다 ABC</p>

High-contrast font preview

가나다 ABC · 한글을 읽어요.

Black font preview

가나다 ABC · 한글을 읽어요.

Use the high-contrast or black class for small body text. Browsers without palette support may retain the original colors.

Load the scripts below in order for pronunciation romanization. Conversion runs in the browser; the API itself does not transmit or store the text.

<script src="https://babypaunch.com/assets/fonts/color-jamo/v1.0/koroman.browser.js"></script>
<script src="https://babypaunch.com/assets/fonts/color-jamo/v1.0/color-jamo.js"></script>
<script>
  ColorJamo.romanize("국물", { syllableSeparator: "_" }); // gung_mul
  ColorJamo.withPronunciation("국물"); // 국물\ngungmul
</script>

syllableSeparator accepts an empty string, a space, or an underscore. Punctuation and English text are preserved; withPronunciation adds pronunciation below lines containing Hangul. Some words and proper names may differ. Display the return value with textContent.
