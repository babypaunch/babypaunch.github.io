Support · Chord Sketch

Chord Sketch Support

Find help with the app, sketch files, and deleting local data.

Using the app

Select a key and Major or Minor on the chord wheel, then press a chord to hear it. Select a slot in the 4-chord sketch before pressing a chord to place it in that slot. You can adjust BPM and time signature, then loop the entire sketch or a single block.

Sketch files

Export creates a JSON file for the current sketch and opens the Android share sheet. Import lets you choose a JSON file previously exported by Chord Sketch through the Android file picker. Export important sketches to another location before uninstalling the app.

Deleting data

Chord Sketch has no user account and stores no user data on a developer-operated server. You can remove settings stored on your device in the following ways.

Clear app settings

Path: Android Settings → Apps → Chord Sketch → Storage → Clear data

Remove the app and settings

Method: Uninstall Chord Sketch to remove its internal settings.

Delete exported files

Method: Delete each JSON file from the app or location where you saved or shared it.

No separate account-deletion request is needed because no account or sketch is stored on a server.

Report a problem or ask a question

Email babypaunch@gmail.com with your device model, Android version, what happened, and steps to reproduce the issue. Include only the relevant part of a screenshot and hide personal information, payment details, and passwords.

For more information, read the Chord Sketch Privacy Policy.
